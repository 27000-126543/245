# 智慧法院全流程办案管理平台 PRD

## 1. 产品概述

智慧法院全流程办案管理平台是一套覆盖法院立案、分案、送达、排期、庭审、文书、审限、执行全流程的智能化管理系统。通过AI推荐、自动冲突检测、三级审批、实时数据大屏等核心功能，实现办案流程数字化、智能化，提升审判效率和质量。

- 主要解决传统法院办案流程繁琐、人工分案效率低、时间冲突难以避免、文书撰写耗时、审限管理不及时、执行环节信息孤岛等痛点
- 目标用户：书记员、法官、庭长、院长、系统管理员
- 产品价值：提升办案效率30%以上，减少人工差错，实现审判质效透明化管理

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 书记员 | 管理员分配 | 立案登记录入、卷宗材料上传、送达操作、庭审记录 |
| 法官 | 管理员分配 | 办理本人案件、撰写文书、查看庭审记录、申请审限延长 |
| 庭长 | 管理员分配 | 查看本庭所有案件、审批本庭文书、查看本庭质效数据 |
| 院长 | 管理员分配 | 全局数据查看、全院质效分析、跨庭案件协调 |
| 管理员 | 系统初始化 | 用户管理、权限配置、规则维护、系统设置 |

### 2.2 功能模块

1. **首页大屏**：实时数据展示、质效指标、热力图、数据筛选
2. **立案管理**：起诉材料录入、案由选择、智能分案推荐、预计时长展示
3. **分案管理**：自动分案、电子卷宗生成、卷宗材料管理
4. **送达管理**：多方式送达（短信/邮件/公告）、送达回执管理
5. **排期管理**：智能排期、冲突检测、排队队列、通知推送
6. **庭审管理**：庭审录音录像、语音转文字、庭审笔录关联
7. **文书管理**：智能推荐判决要点、文书撰写、三级审批、越级提醒
8. **审限管理**：审限预警、延长申请在线审批
9. **执行管理**：财产查控对接、查封冻结文书生成、款物分配
10. **系统管理**：用户管理、权限配置、规则维护

## 3. 核心流程

### 3.1 案件全流程

```mermaid
flowchart LR
    A["当事人提交起诉材料"] --> B["书记员立案登记"]
    B --> C["系统智能推荐承办庭室和法官"]
    C --> D["确认分案，生成电子卷宗"]
    D --> E["送达诉讼文书（短信/邮件/公告）"]
    E --> F["送达回执归入卷宗"]
    F --> G["开庭排期（冲突检测/排队）"]
    G --> H["庭审（录音录像+转文字）"]
    H --> I["文书撰写（智能推荐要点）"]
    I --> J["三级审批（超48h自动越级）"]
    J --> K["审限监控（到期前15天预警）"]
    K --> L["结案归档"]
    L --> M["执行案件（财产查控+查封+款物分配）"]
```

### 3.2 文书审批流程

```mermaid
flowchart LR
    A["法官撰写文书初稿"] --> B["庭长审批"]
    B --> C{48小时内?}
    C -->|是| D["分管院长审批"]
    C -->|否| E["自动越级至院长"]
    D --> F{审批通过?}
    E --> F
    F -->|通过| G["文书生效"]
    F -->|驳回| H["退回修改"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝（#1e3a5f）代表权威、专业、公正
- **辅助色**：金色（#c9a962）点缀，体现庄重感
- **强调色**：红色（#e74c3c）用于预警，绿色（#27ae60）用于完成状态
- **中性色**：深灰（#2c3e50）、中灰（#7f8c8d）、浅灰（#ecf0f1）
- **按钮风格**：矩形微圆角，悬浮有阴影效果，体现稳重感
- **字体**：思源宋体（标题）+ 思源黑体（正文），体现法律文书的正式感
- **布局风格**：卡片式布局，侧边导航+顶部工具栏+主内容区
- **图标风格**：线性图标，简洁专业

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 登录页 | 登录表单 | 深蓝色背景、金色装饰条、居中卡片式登录框、法律元素装饰 |
| 首页大屏 | 数据概览 | 深色主题、大屏布局、数据卡片网格化、热力图可视化、动态刷新效果 |
| 首页大屏 | 顶部导航 | 侧边栏折叠菜单、顶部用户信息、全局通知、系统时间 |
| 业务页面 | 通用布局 | 面包屑导航、筛选工具栏、数据表格、分页控件、操作按钮组 |
| 弹窗组件 | 表单弹窗 | 半透明遮罩、居中弹窗、表单标签左对齐、确定取消按钮 |

### 4.3 响应式

- 桌面优先设计，适配1920×1080及以上分辨率
- 支持平板横屏自适应，最小支持1366×768
- 侧边栏可折叠，数据表格支持横向滚动

### 4.4 动效设计

- 页面切换：淡入淡出过渡
- 数据大屏：数字滚动动画、图表缓动效果
- 按钮交互：点击缩放反馈、悬浮阴影加深
- 通知提示：右上角滑入动画
- 加载状态：骨架屏占位、环形加载动画
